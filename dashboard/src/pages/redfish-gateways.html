DMTF Redfish REST API Endpoints

Open Service Root (/redfish/v1)

The broker exposes standard Redfish v1.18.0 REST endpoints over HTTP/HTTPS. Sensor telemetry ingested from MQTT topics is normalized and queryable through these standard paths:

Method Endpoint URI Description Quick Launch
GET /redfish/v1 ServiceRoot entry point & service collection links Open
GET /redfish/v1/odata OData 4.0 Service Document Open
GET /redfish/v1/$metadata CSDL XML Schema definition & entity schemas Open
GET /redfish/v1/Chassis List of all configured Redfish Chassis units Open
GET /redfish/v1/Chassis/{ChassisID} Chassis details, sensor collection links, and power/thermal models Per Chassis
GET /redfish/v1/Chassis/{ChassisID}/Sensors Collection of all active MQTT sensors mapped to this Chassis Per Chassis
GET /redfish/v1/Chassis/{ChassisID}/Sensors/{SensorID} Individual sensor real-time reading, health status, and thresholds Per Sensor
GET /redfish/v1/Chassis/{ChassisID}/Thermal Legacy DMTF Thermal view (Temperatures & Fans) Per Chassis
GET /redfish/v1/Chassis/{ChassisID}/Power Legacy DMTF Power view (Voltages & PowerSupplies) Per Chassis
GET /redfish/v1/Systems ComputerSystem collection and server system models Open
GET /redfish/v1/Managers Manager collection (MonsterMQ Edge BMC manager) Open
GET /redfish/v1/TelemetryService Telemetry service and metric report definitions Open
